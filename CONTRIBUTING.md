# Contributing

Looma is an early UI prototype. Feedback is welcome; the project license is still undecided, so please discuss substantial code contributions with the owner before submitting them.

## Report a problem
Open an Issue with:
- What you expected and what happened.
- Steps to reproduce.
- Browser or Windows version, selected language and whether this is the standalone HTML or a native build.
- A screenshot if useful, with private information removed.

Never include access tokens, passwords, private keys, personal account data or unredacted logs. Do not publish security-sensitive exploit details in public issues; arrange a private reporting channel with the owner first.

## Suggest a feature
Read [ROADMAP.md](ROADMAP.md), check for an existing issue, and explain the user problem. Games-first launcher functionality takes priority over social features.

## Development changes
Use a separate branch and a focused pull request. Run `npm ci` and `npm run build`; describe what you tested and what remains unverified. Do not mark native behavior as tested based only on the browser preview. Do not commit dependencies, native build outputs or credentials.

## فارسی
برای گزارش مشکل، مراحل تکرار، نتیجهٔ مورد انتظار، نتیجهٔ واقعی، نسخهٔ ویندوز/مرورگر و زبان انتخابی را بنویسید. اطلاعات محرمانه را از عکس‌ها و گزارش‌ها حذف کنید. پیش از پیشنهاد قابلیت، رودمپ و Issueهای موجود را بررسی کنید. برای مشارکت کدنویسی گسترده، ابتدا با مالک پروژه دربارهٔ محدوده و مجوز هماهنگ کنید.
